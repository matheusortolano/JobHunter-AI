JobHunter AI

JobHunter AI é um projeto pessoal de automação para busca, organização e análise de vagas de emprego.

O sistema coleta vagas de fontes públicas e APIs, aplica filtros de relevância, armazena os resultados localmente e utiliza inteligência artificial para auxiliar na priorização das oportunidades.

O acesso ao Gmail é utilizado exclusivamente para enviar relatórios de vagas ao próprio usuário autorizado.
