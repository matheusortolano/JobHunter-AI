Política de Privacidade

Última atualização: 7 de setembro de 2026.

O JobHunter AI é um projeto pessoal utilizado por seu próprio desenvolvedor para organizar e analisar oportunidades de emprego.

Dados utilizados

O aplicativo pode processar informações públicas de vagas de emprego, dados profissionais fornecidos pelo próprio usuário e informações necessárias para gerar relatórios.

Uso da API do Gmail

O acesso ao Gmail é limitado à permissão de envio de mensagens. O JobHunter AI não solicita permissão para ler, modificar ou excluir mensagens da caixa postal.

A autorização é utilizada exclusivamente para enviar relatórios de vagas ao próprio usuário autorizado.

Armazenamento

Credenciais OAuth, tokens e dados pessoais são armazenados localmente no computador do usuário e não são publicados no repositório público do projeto.

Compartilhamento

O JobHunter AI não vende nem compartilha dados pessoais com terceiros para fins publicitários.

Revogação de acesso

O usuário pode revogar o acesso concedido ao aplicativo a qualquer momento pelas configurações de segurança da Conta Google.
